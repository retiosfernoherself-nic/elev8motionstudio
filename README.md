# Elev8 Motion Studio

The website for Elev8 Motion Studio: animated flyers, menus and media for food and drink brands. Founded by Precious Muiambo.

## What's here

- `index.html`: the website
- `media/`: every image and video on the site
- `content/work.js`: the list of work shown on the site. Add new pieces at the top of `window.WORK`; the newest two show at the top of the page and older ones move to "Our work" automatically.

## Publishing

The site is published with GitHub Pages: **Settings › Pages › Deploy from a branch › main / (root)**. Every commit goes live a minute or two later.

Consult enquiries are emailed to elev8motionstudio@gmail.com through FormSubmit. The first enquiry sends an activation email that has to be clicked once.
